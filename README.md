# Wazuh-SIEM-Deployment
Setting up a SIEM tool on a virtual machine to practice log analysis.
In this project, I practiced configuring and deploying a SIEM tool on a Linux Mint Virtual machine ran on VirtualBox. Through this experience, I was able to learn more about SIEM and how logs can be captured and analysed to help detect and prevent potential threats
